## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com foco em performance, design limpo e experiência de usuário inspirada em ambientes de desenvolvimento (IDEs):

* **HTML5 & CSS3** / **TailwindCSS** — Estilização moderna e responsiva.
* **JavaScript (Vanilla)** — Interatividade, animações personalizadas e manipulação de DOM.
* **Design System Próprio** — Estética voltada para desenvolvedores (com componentes imitando editores de código e animação *typewriter*).

---

## ✨ Funcionalidades

* **Efeito Datilografia (*Typewriter*):** Simulação de digitação em tempo real na introdução e nos distintivos de status.
* **Layout Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops.
* **Componentes Estilizados:** Abas de IDE simuladas, blocos de código customizados e suporte a temas escuros.
* **Formulário de Contato Dinâmico:** Validação de campos no front-end e redirecionamento automatizado para o cliente de e-mail.

---

## ⚙️ Como Executar Localmente

Como este portfólio é uma aplicação estática baseada em HTML, CSS e JavaScript, você pode executá-lo de forma muito simples:

1. Clone ou baixe este repositório para o seu computador.
2. Certifique-se de que a estrutura de pastas (`fonts/` e `img/`) esteja correta.
3. Abra o arquivo **`index.html`** diretamente no seu navegador de preferência (ou utilize uma extensão como o *Live Server* no VS Code para melhor experiência).
